# Operica macOS 图标设计规范

## 目的

统一 Operica 桌面端在 macOS Finder、Dock、窗口和安装包中的图标比例，避免图形过大、底板过满或底板被误处理为透明。

## 母版

| 项目 | 规范 |
| --- | --- |
| 画布 | `1024 × 1024 px` |
| 主格式 | SVG（可编辑源文件） |
| 运行时格式 | PNG，RGBA，`1024 × 1024 px` |
| 安装包格式 | ICNS |
| 色彩 | sRGB |
| 底板 | 深色、不透明圆角矩形 |
| 外侧区域 | 圆角外保留透明区域，交由 macOS 进行最终外框处理 |

## 比例与间距

以 Chrome 当前 macOS 图标的有效内容比例作为视觉参考：有效内容约占母版的 `888 × 888 px`，四周留白约 `68 px`。

### 底板几何尺寸

- 位置：`x = 68 px`、`y = 68 px`
- 尺寸：`888 × 888 px`
- 圆角半径：约 `192 px`
- 底板填充：`#0F1835`，保持完全不透明

### 内边框

- 位置：`x = 76 px`、`y = 76 px`
- 尺寸：`872 × 872 px`
- 圆角半径：约 `184 px`
- 描边颜色：`#263B67`
- 描边宽度：约 `6 px`

SVG 中使用 256pt viewBox 时，上述尺寸按 4 倍缩放：

```text
底板：x=17，y=17，width=222，height=222，rx=48
内框：x=19，y=19，width=218，height=218，rx=46
```

## 主体图形

- 主体图形保持现有 Operica 标志、渐变、阴影和中心任务标记。
- 主体不得被改成透明或半透明。
- 主体应落在底板安全区域内，不触碰底板边缘。
- 不额外增加外部投影，避免与 macOS Dock/Finder 的系统阴影叠加。
- 不在 PNG 或 ICNS 中预先裁切成非正方形画布。

## 导出规格

ICNS 至少包含以下尺寸及对应的 `@2x` 资源：

```text
16 × 16
32 × 32
128 × 128
256 × 256
512 × 512
1024 × 1024
```

导出检查：

1. PNG 尺寸必须为 `1024 × 1024 px`。
2. 底板内部像素的 Alpha 必须为 `255`。
3. 有效内容边界应接近 `66–68 px` 到 `956–958 px`，不要超过 Chrome 参考比例。
4. ICNS 应从同一份 PNG 母版生成，不要分别调整各尺寸的主体比例。
5. Finder、Dock、窗口图标和安装包使用同一套 macOS 图标比例。

## 文件职责

| 文件 | 用途 |
| --- | --- |
| `build/icon-mac.svg` | macOS 图标的可编辑源文件 |
| `resources/icon-mac.png` | Electron 运行时 Dock/窗口图标 |
| `build/icon.icns` | electron-builder macOS 安装包图标 |
| `build/icon-mac.icns` | macOS 图标预览及备用资源 |

## 禁止事项

- 不要把不透明底板改成整块透明。
- 不要把主体放大到贴近 `1024 × 1024` 画布边缘。
- 不要为 macOS 单独制作一套更大的主体比例。
- 不要在导出时改变 SVG 中的渐变方向、颜色或中心标记位置。
