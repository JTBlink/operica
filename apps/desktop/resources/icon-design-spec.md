# Operica macOS 图标设计规范

## 目的

统一 Operica 桌面端在 macOS Finder、Dock、窗口和安装包中的图标比例，避免图形过大、底板过满或底板被误处理为透明。

## 母版

| 项目 | 规范 |
| --- | --- |
| 画布 | `1024 × 1024 px` |
| 主格式 | SVG（可编辑源文件） |
| 运行时格式 | PNG，RGBA，`1024 × 1024 px` |
| 安装包格式 | ICNS |
| 色彩 | sRGB |
| 底板 | 深色、不透明圆角矩形 |
| 外侧区域 | 圆角外保留透明区域，交由 macOS 进行最终外框处理 |

## 比例与间距

以 Chrome 当前 macOS 图标的实际底板比例作为视觉参考：底板约占母版的 `830 × 830 px`，四周留白约 `97 px`；阴影扩散后的有效边界约为 `888 × 888 px`。Chrome 主体到底板边缘的留白约为 `56 px`，Operica 采用更宽的安全留白，避免图形在 Finder/Dock 中显得过大。

### 底板几何尺寸

- 位置：`x = 97 px`、`y = 97 px`
- 尺寸：`830 × 830 px`
- 圆角半径：约 `192 px`（与 Chrome/Edge 的 `188–192 px` 视觉范围对齐）
- 底板填充：`#0F1835`，保持完全不透明

### 内边框

- 位置：`x = 105 px`、`y = 105 px`
- 尺寸：`814 × 814 px`
- 圆角半径：约 `184 px`
- 描边颜色：`#263B67`
- 描边宽度：约 `6 px`

SVG 中使用 256pt viewBox 时，上述尺寸按 4 倍缩放：

```text
底板：x=24.25，y=24.25，width=207.5，height=207.5，rx=48
内框：x=26.25，y=26.25，width=203.5，height=203.5，rx=46
```

## 主体图形

- 主体图形保持现有 Operica 标志、渐变、阴影和中心任务标记。
- 主体图形相对原始 SVG 路径使用 `0.95×` 缩放，以画布中心为基准并向上偏移约 `13 px`，抵消底部阴影的视觉重量。
- 以主体主色/高亮区域的可见边界测量，主体到底板边缘的留白约为：水平 `90–95 px`、垂直 `80–85 px`；四边最小安全间距不得小于 `80 px`。
- 中心任务标记随主体等比缩放，不单独放大，确保内部图形与外框的呼吸感一致。
- 主体不得被改成透明或半透明。
- 主体应落在底板安全区域内，不触碰底板边缘。
- 不额外增加外部投影，避免与 macOS Dock/Finder 的系统阴影叠加。
- 不在 PNG 或 ICNS 中预先裁切成非正方形画布。

## 导出规格

ICNS 至少包含以下尺寸及对应的 `@2x` 资源：

```text
16 × 16
32 × 32
128 × 128
256 × 256
512 × 512
1024 × 1024
```

导出检查：

1. PNG 尺寸必须为 `1024 × 1024 px`。
2. 底板内部像素的 Alpha 必须为 `255`。
3. 底板边界应接近 `97–105 px` 到 `919–927 px`；含抗锯齿和阴影的有效边界可扩展到约 `68–956 px`。
4. 主体主色/高亮边界到底板边缘的间距应保持在水平 `90–95 px`、垂直 `80–85 px`，且任一方向不得小于 `80 px`；顶部和底部不得出现明显失衡。
5. ICNS 应从同一份 PNG 母版生成，不要分别调整各尺寸的主体比例。
6. Finder、Dock、窗口图标和安装包使用同一套 macOS 图标比例。

## 文件职责

| 文件 | 用途 |
| --- | --- |
| `build/icon-mac.svg` | macOS 图标的可编辑源文件 |
| `resources/icon-mac.png` | Electron 运行时 Dock/窗口图标 |
| `build/icon.icns` | electron-builder macOS 安装包图标 |
| `build/icon-mac.icns` | macOS 图标预览及备用资源 |

## 禁止事项

- 不要把不透明底板改成整块透明。
- 不要把主体放大到贴近 `1024 × 1024` 画布边缘。
- 不要为 macOS 单独制作一套更大的主体比例。
- 不要在导出时改变 SVG 中的渐变方向、颜色或中心标记位置。
